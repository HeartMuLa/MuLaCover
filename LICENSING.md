# MuLaCover Licensing Guide

MuLaCover uses separate terms for source code, official model weights,
generated outputs, and third-party components. The license shown by GitHub in
the repository sidebar applies to the source-code repository; it does not grant
commercial rights to the official MuLaCover weights or their outputs.

## License by material

| Material | Governing terms | Commercial use |
| --- | --- | --- |
| MuLaCover source code and documentation | [Apache License 2.0](LICENSE) | Permitted subject to Apache-2.0 |
| Official MuLaCover model weights and derivatives of those weights | CC BY-NC 4.0 and [MODEL_LICENSE](MODEL_LICENSE) | Prohibited without a separate written license |
| Outputs generated using official MuLaCover weights | [MODEL_LICENSE](MODEL_LICENSE) | Prohibited without a separate written license |
| Third-party code, models, and other components | The component's own license and notices | Determined by the applicable third-party terms |

## Important boundaries

- Installing or using the Apache-2.0-licensed Python package does not grant a
  license to MuLaCover model weights.
- Receiving or downloading official model weights means the weight and output
  terms apply in addition to any source-code license.
- Users must obtain all rights required for reference recordings,
  compositions, lyrics, performances, voices, datasets, and generated works.
- A commercial license for the official weights or their outputs requires
  separate written authorization from MuLa Labs.

## Controlling documents

This guide is a plain-language overview. If it conflicts with a governing
license, the following documents control for their respective materials:

1. [`LICENSE`](LICENSE) for MuLaCover source code and documentation.
2. [`MODEL_LICENSE`](MODEL_LICENSE) for official model weights and outputs.
3. The license and notice shipped with each third-party component.

Use only links published through the official MuLa Labs repository.
