# Security Policy

## Supported versions

MuLaCover has not made its first public release. Security fixes currently
target the latest commit on the default branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or Discord
message. Use GitHub's private vulnerability reporting when it is available. If
that option is unavailable, email
[contact@mulalabs.ai](mailto:contact@mulalabs.ai) and share only enough
information to establish a private communication channel.

Include affected versions, impact, reproduction steps, and any suggested
mitigation. Do not access data that is not yours or disrupt third-party systems
while researching a vulnerability.
